# المحطات القرآنية
تطبيق ويب عربي مستقل لخطة حفظ ومراجعة القرآن الكريم على مصحف المدينة (604 صفحة). لا يرتبط بأي تطبيق سابق ولا يعدّل بياناته.

## الخطة
- 87 محطة: 86 محطة × 7 صفحات = 602 صفحة، ثم المحطة 87 للصفحتين 603–604.
- الأيام 1–87: محطة في اليوم حسب ترقيم الصفحات بغض النظر عن حدود السور.
- الأيام 88–90: مراجعة عامة (المحطات 1–29، 30–58، 59–87).
- أسماء المحطات عناوين تنظيمية وتدبرية، وليست أسماء سور أو تفسيرات معتمدة؛ يمكن تغييرها والسؤال الاختياري.
- التسجيل منفصل: قراءة / حفظ / تسميع / إتقان. الإتقان الفعلي يختلف عن مجرد إنهاء صفحات الخطة.
- مراجعات متباعدة بعد تسجيل الإتقان: بعد يوم، ثم 7 أيام من آخر مراجعة، ثم 30 يومًا من آخر مراجعة، ثم شهريًا.

## التقنية والخصوصية
HTML + CSS + JavaScript دون خدمات خارجية أو تسجيل حساب. حفظ البيانات بـ localStorage في **المتصفح الحالي فقط**. لا يوجد مزامنة بين الأجهزة. حذف بيانات الموقع أو استخدام متصفح آخر يفقد التقدم ما لم تستعد نسخة JSON المصدّرة. ينصح بحفظ النسخة الاحتياطية دوريًا.

واجهة التسجيل والمحطات تعمل دون إنترنت بعد الزيارة الأولى وتثبيت الملفات في Service Worker. زر «فتح المصحف» يفتح صفحة Quran.com ويحتاج اتصالًا بالإنترنت. التطبيق لا يعيد عرض نص قرآني مضمّن منعًا للخلط بين طبعات المصاحف.

يمكن تنزيل ملف ICS لإضافة جدول 90 يومًا إلى التقويم. الاستيراد والتذكيرات يعتمد على تطبيق التقويم المستخدم؛ لا توجد إشعارات هاتفية خلفية مضمونة من تطبيق المحطات نفسه.

## التشغيل والنشر
- محليًا: افتح `index.html` في المتصفح؛ قد لا يعمل عامل الخدمة على `file://`، لكن متابعة المحطات تعمل.
- GitHub Pages: افتح Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** → Folder: **/(root)** → Save. يجب تفعيل ذلك مرة واحدة من إعدادات GitHub؛ لا يمتلك تكامل التطبيق إذن تفعيل Pages نيابة عن مالك المستودع.
- المسار المعتاد بعد التفعيل: https://drburghash-sys.github.io/quran-stations/
- يمكن إضافته لشاشة الهاتف الرئيسية من قائمة المتصفح بعد تفعيل GitHub Pages.

## الملفات
- `index.html`: الواجهة.
- `style.css`: تصميم متجاوب بنمطين فاتح وداكن.
- `app.js`: 87 محطة ونظام الحفظ والتسميع والمراجعة والتصدير.
- `manifest.webmanifest` و`icon.svg`: هوية التطبيق.
- `sw.js`: تخزين ملفات الواجهة للاستخدام دون اتصال.

**ملاحظة:** الحفظ سبع صفحات جديدة يوميًا شديد الكثافة؛ يسمح التطبيق بمواصلة المحطات بعد اليوم التسعين دون تغيير سجل الإتقان.
